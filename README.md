# Private AI Platform

Plataforma de IA privada: chat con documentos propios, con citas a la fuente, que corre en infraestructura del cliente.

**Estado:** Sprint 0, en construcción.

## Estructura

- `backend/` — API y lógica de la plataforma.
- `frontend/` — interfaz de chat.
- `deploy/` — definición del despliegue en la infraestructura del cliente.
- `data/sample-docs/` — documentos de ejemplo para pruebas.
- `docs/product/` — alcance y decisiones de producto.
- `docs/architecture/adr/` — registros de decisiones de arquitectura ([índice](docs/architecture/adr/)).
- `docs/evaluation/` — cómo se evalúa la calidad de las respuestas.
- `docs/operations/` — operación y puesta en marcha.
- `docs/sprint-log/` — evidencia de cada tarea del sprint.
- `scripts/` — utilidades de desarrollo.
